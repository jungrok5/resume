  migrated the transport layer from gRPC to TCP; introduced sharding-based data distribution.
  Built a single-source pipeline generating server/client code, CSV and validation from proto definitions.
  Load-test measurements: 240,000 gRPC requests/second, 50,000 TPS on EntityFramework.
  Led AI developer productivity: implemented an MCP server in-house, built an AI test/code-review
  agent team, and deployed a local LLM coding stack (llama.cpp) that keeps company code in-house.
- **2023–2024 · NCSOFT, Miniverse (Unreal Engine 5, user-generated sandbox MMO)** — Technical Director.
  50 million props full-tick in a single space with 2,000 concurrent players building densely.

  Client-delegated distributed simulation: applied the Roblox network-ownership concept to NPC AI
  with seamless ownership migration.

## Personal projects (GitHub)

Experiments in how far each domain can be pushed using AI and models as tools.

- **Hellfarm** (private) — Diablo-style loot farming meets Vampire-Survivors-like one-hand
  hack-and-slash action game (Windows/Android), Godot + C#. A node-free, GC-free data-oriented
  engine (struct-of-arrays flat arrays, one MultiMesh draw call per system, custom spatial hash
  instead of a physics engine) that **simulates 128 million entities concurrently with max-level
  skill combat** (192 million verified for spawn/simulate/render). Optimized the O(n²) blow-up of
  dense horde clustering from 2,500 ms to 38 ms per frame — a 38x improvement.
- **ZeroLlama** (private) — Agentic coding client (VS Code extension) built for local-model
  scenarios on consumer GPUs. TypeScript + llama.cpp. Auto-tunes model and quantization choice
  to the available GPU/VRAM, and offloads MoE experts to CPU RAM so a 35B-class model
  (~3B active) runs on 8 GB of VRAM. 35 modules, 27,515 lines of code.
- **ondevice-imagen** — Android app generating postcard images on-device from metadata such as
  weather, place and time. Kotlin + ONNX Runtime; the Stable Diffusion inference pipeline was
  implemented natively for Android. https://github.com/jungrok5/ondevice-imagen
- **one-scroll-bible** — Multilingual mobile web telling the whole Bible's redemptive history as a
  single scroll, in 200+ languages. Vanilla JS, Node, Vercel. Live at https://one-scroll-bible.com/
  https://github.com/jungrok5/one-scroll-bible
- **thesauros** — Service analyzing and alerting on buy timing for Korean and US equities.
  Python, Next.js, Supabase. Runs in production from collection through analysis, backtesting and alerts.
  https://github.com/jungrok5/thesauros
