AI 개발 생산성 향상 · NCSOFT Panthera

문제

서버 기능 하나를 확인하려면 테스트 호출을 짜고, 서버 로그를 뒤지고, DB를 조회하고, 결과를 정리하는 일을 사람이 손으로 이어 붙여야 합니다. 코드리뷰도 프로젝트 전체를 사람이 다 읽기는 어렵습니다.

접근

MCP 서버를 자체 구현해 자연어 테스트 요청을 gRPC 호출 시퀀스로 바꿉니다. 호출할 API는 리플렉션으로 자동 탐색합니다. 테스터 · 분석가 · DB · 서버 매니저 4종의 AI 테스트 에이전트 팀이 테스트 → 로그 분석 → DB 검증 → 보고서를 자동으로 이어 가고, 멀티에이전트 코드리뷰로 서버 · DB 프로젝트를 전수 리뷰합니다.

결과

코드리뷰에서 실제 결함을 다수 발견 · 확정했습니다. 또 사내 코드가 외부로 나가지 않는 llama.cpp 기반 로컬 LLM 코딩 스택을 구축해 배포했습니다(체계적 검증으로 3모델 배포, 구형 RTX 2080 Ti 11GB에서 재현성 검증).

화면 속 요청 문장, API 이름, 로그, DB 행, 코드, 리뷰 코멘트는 이해를 돕기 위한 예시입니다.
