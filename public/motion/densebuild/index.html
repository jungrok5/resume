대규모 UGC 처리 · Miniverse UE5

문제

UGC 샌드박스 MMO의 단일 공간에서 5,000만 개 프랍을 풀 틱으로 처리하고, 2,000명이 한곳에 몰려 건축한다. 여러 스레드가 공유 상태를 직접 바꾸면 락을 잡으려는 대기가 쌓인다.

접근

공간마다 디스패처 하나가 공유 상태를 독점 변경하는 액터 모델로 락을 없앴다(락프리). 한 프레임은 Network → Writable → Space → Broadcast 스테이지로 나눠 읽기는 병렬로, 쓰기만 단일 스레드에서 직렬로 처리한다. 브로드캐스트는 zero-copy(ReferenceBuffer)로 직렬화 1회·할당 1회만 하고 같은 버퍼를 모든 수신자에게 보낸다.

결과

단일 공간 5,000만 프랍 풀 틱 + 동시 2,000명 밀집 건축, 동기화 락 경합 제거. 화면의 점 2,000개는 빌더 수 그대로이고, 프랍 배치·스테이지 폭·입자 흐름은 개념도다(측정값 아님).
