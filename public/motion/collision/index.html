AION2 · 서버 캐릭터 충돌 처리

문제

캐릭터끼리 부딪히고, 담 너머를 보고, 지형 위를 활강하는 판정을 서버도 내려야 했다. 서버에는 클라이언트가 가진 스태틱 메시가 없었다.

접근

서버 충돌 처리의 방향을 정하고 PhysicsWorld · PhysicsSystem · CollisionShapes 구조를 설계했다. 클라이언트 스태틱 메시를 서버에서 충돌 가능한 환경으로 만들고(UE4 데이터 익스포트는 리서치), PC vs PC · NPC vs NPC · PC vs NPC 충돌을 기본 구현했다. 사용할 충돌체 종류와 시야 Ray · 이동 Ray 개념을 정리하고, 지형 충돌(활강, line of sight)을 처리했다.

성능은 grid · kd-tree · 시야 ray 높이 기반 전처리 데이터 생성을 리서치했다.

대규모 Agent 리서치

서버에서 PC vs NPC 20,000개 이동 충돌을 테스트했다. 네비게이션·길찾기 Agent를 다시 구현하고, 이동 범위를 기준으로 충돌 처리를 나누고 업데이트 tick을 분할했다.

화면의 지형, 구조물, 충돌체 모양, 셀 크기, 분할 수, Agent 점의 개수는 이해를 돕기 위한 개념도·예시다. 실제 수치는 테스트 규모 20,000뿐이다.
